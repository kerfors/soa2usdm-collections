RT-13 ECG (activity-level rule): EG-OV → EG
EG-OV: the EG domain contains ECG data, all cycle measurements and all findings from the ECG, including an overall interpretation. EKG and electrocardiogram name the same. An SoA row that names an ECG is routed to EG at activity level, whether the grain is a panel (the protocol names the measurements) or a procedure; which ECG tests are collected stays open. Rows that name placing or removing the device record its handling, not an ECG result.

  • ECGs in footnote xannot-012: Triplicate ECGs. Post randomization ECGs are included in each ISA.
